# Balon

Balon je aplikacija za rezervaciju termina i vođenje sportskih objekata, prvenstveno fudbalskih balona i terena. Jedna platforma opslužuje više objekata, a svaki objekat ima svoje terene, cijene, korisnike i podatke odvojene od ostalih.

Igrači preko booking aplikacije pregledaju slobodne termine i rezervišu teren u par klikova, uz prijavu e-mailom ili Google nalogom.

Osoblje objekta koristi admin aplikaciju za kalendar rezervacija, stalne (ponavljajuće) termine, cjenovnik po terenu i vremenu, evidenciju korisnika, naplatu i smjene. Sistem sam sprječava duple rezervacije, uključujući slučaj kada se cijeli teren i njegove polovine rezervišu u isto vrijeme.
